# VectorCraft command catalog

Generated from `list_commands` (VectorCraft 0.7.0). Run any of these with `run_command {command, params}`;
read one live with the `vectorcraft://command/{id}` resource or `list_commands {filter}`. `params` use the engine's shorthand:
`?` = optional, `a|b` = choices, `→ {...}` = what it returns.

## appearance

- `appearance.addFill` (Window › Appearance): {ids?, target?: "object"\|"contents"} add a fill on top of each selected object's own stack (a copy of its top fill; type without one: its characters' fill; else the default fill)
- `appearance.addStroke` (Window › Appearance): {ids?, target?} add a stroke on top of each selected object's own stack (a copy of its top stroke, else the default stroke)
- `appearance.clear` (Window › Appearance): {ids?, target?} leave each object one empty fill and stroke (None; a group none of its own) and reset its opacity and blend mode
- `appearance.reduceToBasic` (Window › Appearance): {ids?, target?} keep only the topmost visible fill and stroke, without their own opacity, blend mode or effects (a group keeps no rows it lacked), and drop the object's effects
- `appearance.setItem`: {index: paint-order item index, ids? (default: the selection), target?: "object"\|"contents", opacity?: 0..100, blend?: name, visible?: bool, weight?: pt (strokes), color?\|none?\|swatch?\|gradient? (as paint.setFill)} edit one fill/stroke of each target object's own appearance stack
- `appearance.removeItem`: {index \| indices: [..] (paint-order item indices), ids?, target?} remove those fills/strokes from each target object's own stack
- `appearance.addEffect`: same as effect.apply (an alias): {effect: id, params?: {…}, item?: appearance item index\|null, ids?, target?} → {ids, index, item}
- `appearance.duplicateItem` (Window › Appearance): {index \| indices: [..] (paint-order item indices), to?: paint-order index of the copy (one `index` only; default: right above it, as Alt-dragging a row places it), ids?, target?} copy fills/strokes with their effects
- `appearance.moveItem`: {from: paint-order item index \| "contents", to, contents?: count, ids?, target?} move fill/stroke `from` to paint-order index `to`; on a group, layer or type the Contents (Characters) row stays between the same items (a moved item landing next to it keeps its side) unless `contents` says how many items paint below it afterwards. from "contents": move that row so `to` items paint below the members (characters) and the rest above → {index: where the item landed \| contents: the row's slot}
- `appearance.copyFrom`: {source: id, ids?, pickUp?, apply? (trees as eyedropper.setOptions, merged over the Eyedropper Options for this call), reverse?: bool, append?: bool} copy the attributes both picked up and applied (by default the whole appearance stack, opacity and blend mode, and from type to type the character and paragraph attributes) from `source` to ids (default: the selection), the fill, stroke and weight also to the paint defaults; `reverse` (Alt-click) copies from the first selected object (or ids) onto `source` instead; `append` (Shift+Alt-click) adds the source's fills, strokes and effects on top of each target's stack; placed gradients land at the same place relative to each target's bounds (defaults: fitted to new art) → {ids}
- `appearance.setActiveItem`: {index: paint-order item index in the first selected object's stack \| null} make that fill/stroke row the target of the paint.setFill/setStroke, stroke.set/setAdvanced, paint.editGradient/setGradientGeom, transparency.set and effect.* calls that omit `item` (a fill row brings the Fill proxy forward, a stroke row the Stroke proxy); null or any selection change clears it → {index}
- `appearance.showAllHidden` (Window › Appearance): {ids?, target?} make every hidden fill, stroke and effect (the object's and each item's) of each selected object visible again; errors when nothing is hidden → {ids}
- `appearance.targetContents`: {ids?} select the members of the selected groups and layers (or `ids`), as double-clicking the Appearance panel's Contents row does: the panel then lists, and appearance edits change, their own appearance; errors when none has members → {ids}
- `appearance.transfer`: {source: id, target: id, copy?: bool} give `target` (a layer, group or object) the appearance (fills, strokes, effects) and transparency (opacity, blend mode, isolation, knockout) of `source`, as dragging a target circle onto another in the Layers panel does; the source is left with a cleared appearance (as appearance.clear) unless `copy` (Alt-drag). Opacity masks stay; placed gradients keep their place relative to each object's bounds → {source, target}
- `appearance.setNewArtBasic` (Window › Appearance): {on?: bool (omitted: toggle)} the Appearance panel option (the preference newArtBasic, on by default): on, new art takes one fill and stroke (with the Stroke panel's options); off, the whole appearance of the last selected object (every fill, stroke and effect, opacity and blend mode) → {on}
- `appearance.newArt`: {} what the next object drawn gets → {basic: New Art Has Basic Appearance, appearance: {items, effects} (the model's JSON; placed gradients relative to the unit box), opacity: 0..100, blend, graphicStyle: the style it is linked to or null, inherited: taken from the last selection}

## artboard

- `artboard.new` (Window › Artboards): {x?, y?, width?, height?, name?} (default: right of the last)
- `artboard.delete` (Window › Artboards): {index}
- `artboard.setProps` (Window › Artboards): {index, name?, x?, y?, width?, height?}
- `artboard.fitToArt` (Object › Artboards): {index?}
- `artboard.fitToSelection` (Object › Artboards): {index?}
- `artboard.move`: {index, dx, dy, moveArt?: bool, copy?: bool} move an artboard (and the art fully inside it; locked and hidden art only with prefs moveLockedWithArtboard); `copy` (Alt-drag) leaves them and moves copies → {index, moved: the art moved or the copies}
- `artboard.convertToArtboards` (Object › Artboards): {} turn each selected object's bounds into a new artboard (the objects are removed) → {artboards}
- `artboard.rearrange` (Object › Artboards): {columns?: n (2), spacing?: pt (20), byColumn?: false, moveArtwork?: true (locked and hidden art only with prefs moveLockedWithArtboard)} lay artboards out in a grid
- `artboard.reorder`: {index, to} change an artboard's number
- `artboard.duplicate` (Window › Artboards): {index?: n (default: the Artboard tool's artboard), art?: bool (default: the Artboard tool's moveArt option)} copy placed right of the last artboard, with copies of the art fully inside it when `art` (locked and hidden art only with prefs moveLockedWithArtboard) → {index, ids: the art's copies}
- `artboard.copy`: {index?, art?} (defaults as artboard.duplicate) put the artboard, and the art fully inside it when `art`, on the clipboard: edit.paste adds a copy right of the last artboard, edit.pasteInPlace/InFront/InBack where it was, in this or another document (one undo step; edit.pasteOnAllArtboards pastes only the art); edit.copy runs this while the Artboard tool is chosen → {copied: objects}
- `artboard.cut`: {index?, art?} artboard.copy, then delete the artboard and that art in one undo step (not the only artboard); edit.cut runs this while the Artboard tool is chosen → {copied: objects}

## assets

- `assets.add` (Object › Collect for Export): {ids?: [id…] (default: the selected objects), multiple?: true (an asset per object; false: one asset of them all), name?: (the asset's name, when it makes one)} collect art as assets for Window › Asset Export and Export for Screens' Assets tab, named after the object (else Asset 1, Asset 2…); art already collected as such an asset keeps it → {assets: [asset id…] (in order), added: n}. Assets follow their art: moving it moves the crop, deleting it removes it from the asset
- `assets.remove`: {assets: [asset id…]} take assets out of the Asset Export panel (their art stays) → {removed: n}
- `assets.rename`: {asset: id, name} rename an asset (its files' names)
- `assets.list`: {} → {assets: [{id, name, nodes: [id…], bounds: [x, y, width, height] \| null (the crop: the visual bounds of its art)}]} the Asset Export panel's assets, in order
- `assets.export`: {assets?: [asset id…] (default all), folder?, zip?, openLocation?, formats?, preset?, settings?, prefix?, subfolders?, antiAlias?} each asset's art alone, cropped to it, in every format row: document.exportForScreens {assets} at the document's export settings (document.exportSettings) under the ones given → what document.exportForScreens returns (no folder: the files, or one zip, as dataBase64). Leaves the remembered settings as they are (assets.settings.set changes them)
- `assets.settings.set`: {formats?, preset?: mobile\|density\|"" (none), settings?, prefix?, subfolders?, antiAlias?} change the export settings the Asset Export panel and Export for Screens share (document.exportSettings; the values of document.exportForScreens; null removes one): formats replace a preset, a preset replaces the formats → {settings}. Not an undo step

## attributes

- `attributes.info`: {ids?, item?} → {ids, overprintFill, overprintStroke, showCenter, imageMap: "none"\|"rectangle"\|"polygon", url, note, fillRule: "nonZero"\|"evenOdd" (of the paths and compound paths in them), reversed (their subpaths run counter-clockwise on screen: Reverse Path Direction On), recentUrls: [newest first]} the Attributes panel's values for `ids` or the selection, overprint aimed as object.setOverprint aims; a value is null where they differ (or nothing has a fill, stroke or path)
- `attributes.set`: {overprintFill?: bool, overprintStroke?: bool (aimed as object.setOverprint's fill and stroke, item? too), showCenter?: bool (the canvas shows the selected object's centre point), imageMap?: "none"\|"rectangle"\|"polygon", url?: string ("" removes it; SVG export links the object), note?: string, ids?} set the Attributes panel's values on ids or the selection, as one undo step; a URL given joins the recent URLs (attributes.info) → {changed: objects}

## brush

- `brush.list`: {} → {brushes: [{name, type}], current}
- `brush.get`: {name} → the brush definition (JSON)
- `brush.apply`: {name, ids?} apply a brush to the strokes of the selected paths (adds a stroke if missing) and make it current → {ids}
- `brush.remove`: {ids?} remove brushes from the selected strokes → {ids}
- `brush.setCurrent`: {name: string\|null} the brush the Paintbrush tool paints with (not an undo step)
- `brush.new`: {type: calligraphic\|scatter\|art\|pattern\|bristle, name?, params?: {…definition fields}, ids?} new brush; art/scatter/pattern brushes take the selected art (pattern: side tile) unless params give it → {name}
- `brush.delete`: {name} delete a brush; strokes using it become plain strokes
- `brush.duplicate`: {name, newName?} → {name}
- `brush.options`: {name, params?: {…fields to change}, newName?} edit a brush definition (strokes using it update) → {name}
- `brush.freehand`: {…path.freehand params, brush} paint a freehand stroke with a brush → {id}

## clipboard

- `clipboard.exportSvg`: {} → {svg} the copied objects as standalone SVG (null when the clipboard is empty)
- `clipboard.importSvg`: {svg \| dataBase64 (SVG or SVGZ bytes), center?: [x, y]} replace the clipboard with the SVG's objects (and the images, patterns and symbols they use), centred on `center` (default: the first artboard) → {count}; then run edit.pasteInPlace
- `clipboard.conflicts`: {} → {swatches: [{name, document, clipboard, spot}]} the global or spot swatches the copied objects use whose name the active document gives another colour (`document`/`clipboard`: #rrggbb): Paste asks Merge or Add for each (pass the answer as edit.paste* {swatchConflict}). Pasting back into the document the objects came from raises none
- `clipboard.exportPng`: {scale?: 1 (pixels per point, up to 64)} → {dataBase64, width, height (px)} the copied objects cropped to their visual bounds, transparent around them (dataBase64 null when the clipboard is empty)
- `clipboard.exportPdf`: {} → {dataBase64} a one-page PDF of the copied objects, the page their visual bounds (null when the clipboard is empty)
- `clipboard.exportText`: {} → {text} the copied type objects' text, one object per line (null unless every copied object is type, or a group of type)
- `clipboard.flavours`: {} → {flavours: [mime…]} what Copy offers other apps for the current clipboard, best first, by the Clipboard Handling preferences: text/plain (a type-only copy's text, else the SVG markup with copyAsSvg), image/svg+xml (copyAsSvg), application/pdf (copyAsPdf), image/png (always; PDF and PNG only for objects with an area); the app publishes them on Copy and Cut
- `clipboard.importImage`: {dataBase64 (PNG, JPEG, GIF, WebP, TIFF or BMP bytes), mime?: the type the system clipboard gave (an image/… type; the format is read from the bytes), center?: [x, y]} replace the clipboard with the image, embedded at 100% of its physical size (its resolution, else 72 ppi), centred on `center` (default: the first artboard) → {count, width, height (pt), pixelWidth, pixelHeight}; then run edit.paste
- `clipboard.importText`: {text, center?: [x, y]} replace the clipboard with point text of `text` (one paragraph per line; trailing line breaks dropped) in the default type style, centred on `center` (default: the first artboard) → {count}; then run edit.paste
- `clipboard.importPdf`: {dataBase64, page?: 1, password? (an encrypted PDF), center?: [x, y]} replace the clipboard with the objects of one PDF page (with the images, patterns and swatches they use), centred on `center` (default: the first artboard) → {count, warnings}; then run edit.paste
- `clipboard.importEmf`: {dataBase64 (EMF or WMF bytes), center?: [x, y]} replace the clipboard with the picture's objects (paths, clipping groups, images, point type; the images they use), centred on `center` (default: the first artboard) → {count, warnings}; records VectorCraft doesn't read are skipped with one warning; then run edit.paste

## command
